Mise en place d’une stratégie de sauvegarde automatisée (Windows Server Backup)

Présentation

Déploiement d’une sauvegarde planifiée pour protéger l’état système et les données critiques du serveur.

Objectifs

  • Ajouter un stockage dédié aux sauvegardes.
  • Installer Windows Server Backup.
  • Créer une planification quotidienne.
  • Inclure l’état système et les données critiques.
  • Lancer une sauvegarde de test.
  • Valider le statut de réussite.

Environnement technique

  • Hyperviseur : VMware Workstation Pro
  • Serveur : Windows Server 2022
  • Rôles protégés : AD DS, DNS, serveur de fichiers
  • Outil : Windows Server Backup

Démarche réalisée

  • Ajout d’un second disque virtuel dédié aux archives de sauvegarde.
  • Installation de la fonctionnalité Windows Server Backup.
  • Configuration d’une planification personnalisée quotidienne.
  • Sélection de l’état système et des données du serveur de fichiers.
  • Exécution manuelle d’un test de recette et validation de la réussite.

Résultats obtenus

  • Stockage de sauvegarde dédié créé.
  • Sauvegarde planifiée configurée.
  • État système protégé.
  • Test manuel réussi.
  • Base de PRA documentée.
