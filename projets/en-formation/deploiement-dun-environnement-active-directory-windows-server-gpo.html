Déploiement d’un environnement Active Directory (Windows Server / GPO)

Présentation

Installation d’un contrôleur de domaine, structuration de l’annuaire, intégration d’un poste client et application d’une GPO.

Objectifs

  • Isoler l’environnement virtuel.
  • Installer AD DS et DNS.
  • Promouvoir le serveur en contrôleur de domaine.
  • Structurer l’annuaire.
  • Déployer une GPO de restriction.
  • Intégrer un poste client et valider.

Environnement technique

  • Hyperviseur : VMware Workstation Pro
  • Serveur : Windows Server 2022
  • Client : Windows 11 Professionnel
  • Technologies : AD DS, DNS, GPO, Kerberos, LDAP

Démarche réalisée

  • Création d’un réseau virtuel isolé et configuration IP statique.
  • Installation du rôle AD DS et promotion en contrôleur de domaine racine.
  • Structuration de l’annuaire avec OU, groupes et utilisateurs.
  • Création d’une GPO de restriction liée à l’OU cible.
  • Configuration DNS du poste client, jonction au domaine et test d’authentification.
  • Validation de l’application de la GPO sur le poste Windows 11.

Résultats obtenus

  • Contrôleur de domaine fonctionnel.
  • Annuaire structuré.
  • Poste client joint au domaine.
  • Authentification réseau validée.
  • GPO appliquée correctement.
