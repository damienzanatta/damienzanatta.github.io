Configurations initiales d’un commutateur Cisco (Packet Tracer)

Présentation

Configuration de base d’un commutateur Cisco : nom d’hôte, accès console, mots de passe, bannière et sauvegarde.

Objectifs

  • Renommer le commutateur.
  • Sécuriser l’accès console.
  • Protéger le mode privilégié.
  • Chiffrer les mots de passe.
  • Ajouter une bannière MOTD.
  • Sauvegarder la configuration.

Environnement technique

  • Logiciel : Cisco Packet Tracer
  • Équipements : commutateurs Cisco
  • Interface : CLI Cisco IOS

Démarche réalisée

  • Consultation de la configuration initiale avec show running-config.
  • Configuration du nom d’hôte et des accès d’administration.
  • Activation du chiffrement des mots de passe et ajout d’une bannière d’avertissement.
  • Vérification de la demande de mot de passe à la reconnexion.
  • Sauvegarde de la configuration pour la rendre persistante.

Résultats obtenus

  • Nom d’hôte configuré.
  • Accès console protégé.
  • Mode privilégié sécurisé.
  • Mots de passe chiffrés.
  • Bannière MOTD affichée.
  • Configuration sauvegardée.
